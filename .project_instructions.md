# ASCEND — YKS Disiplin Uygulaması

## Proje Özeti
ASCEND, YKS öğrencileri için AI destekli, premium dark-theme bir disiplin yönetim sistemidir.

## Tasarım Sistemi
- **Arka plan:** #0a0a0a, #111111
- **Accent:** #f97316, #ea580c (turuncu)
- **Glassmorphism:** backdrop-blur, yarı-saydam border
- **Font:** Inter
- **Animasyonlar:** Framer Motion
- **Dil:** Tüm UI Türkçe

## Sayfa Yapısı
- `/` — Landing page (hero, features, testimonials, pricing, FAQ)
- `/login`, `/register` — Auth sayfaları
- `/onboarding` — 5 adımlı wizard
- `/dashboard` — Ana kontrol paneli (streak, XP, tasks, chart)
- `/dashboard/planner` — Günlük planlayıcı
- `/dashboard/tasks` — Görev yönetimi (CRUD + disiplin motoru)
- `/dashboard/pomodoro` — Pomodoro timer + Focus Mode
- `/dashboard/stats` — İstatistikler + 365 gün heatmap
- `/dashboard/questions` — Soru takibi
- `/dashboard/achievements` — Steam-tarzı başarımlar
- `/dashboard/ai-coach` — LLM API ile streaming AI chat
- `/dashboard/settings` — Profil ve çalışma ayarları

## Teknik Kararlar
- Auth: NextAuth v4 + Credentials provider + JWT strategy
- DB: PostgreSQL + Prisma ORM
- AI: Built-in LLM API (gpt-5.4-mini) with streaming
- Charts: Recharts (bar, line)
- Gamification: XP system with 7 level tiers, achievements
- Discipline Engine: Auto-mark missed tasks, XP penalty (-25), productivity drop

## XP Sistemi
- Görev tamamla: +50 × öncelik çarpanı
- Pomodoro: +25
- Doğru cevap: +1/soru
- Kaçırılan görev: -25
